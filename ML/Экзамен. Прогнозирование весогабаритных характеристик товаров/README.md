# Прогнозирование весогабаритных характеристик товаров

Решение задачи прогнозирования весогабаритных характеристик товаров (вес, высота, ширина, длина) на основе мультимодального подхода с использованием табличных, текстовых и визуальных признаков.

## 📊 Результаты

**Финальный Score:** 0.411577 (Macro Log-MAE)

**Улучшение относительно baseline:** ~7.1% (0.443 → 0.412)

## 🎯 Описание задачи

Необходимо предсказать 4 весогабаритные характеристики товаров:
- `weight` (вес в кг)
- `height` (высота в см)
- `width` (ширина в см)
- `length` (длина в см)

**Метрика:** Macro Log-MAE (среднее MAE по log1p-трансформированным таргетам)

## 🔧 Архитектура решения

### Этапы пайплайна

1. **EDA (01_eda.py)**
   - Анализ распределений целевых переменных
   - Выявление корреляций
   - Анализ категориальных и текстовых признаков
   - Визуализация

2. **Предобработка данных (02_data_pipeline.py)**
   - Обработка пропусков
   - Label Encoding для категорий
   - Стандартизация числовых признаков
   - Извлечение временных признаков
   - Log1p трансформация таргетов

3. **Baseline модель (03_baseline_model.py)**
   - LightGBM с базовыми параметрами
   - Только табличные признаки
   - Score: 0.443

4. **Текстовые признаки (04_text_features_model.py)**
   - TF-IDF векторизация (300 признаков)
   - Извлечение размерных характеристик regex
   - Улучшение: ~2% относительно baseline

5. **Image features (05_image_features_extractor.py)**
   - ResNet50 embeddings (2048 признаков)
   - Batch processing с GPU
   - Кэширование результатов

6. **Финальная модель (07_final_training.py)**
   - Объединение всех типов признаков (~2414 признаков)
   - Оптимизированные гиперпараметры LightGBM
   - Score: 0.411577

### Типы признаков

| Тип | Количество | Описание |
|-----|-----------|----------|
| Табличные | ~16 | Категории, цена, временные признаки |
| Текстовые | ~50 | Размерные характеристики из текста |
| TF-IDF | 300 | Векторизация title и description |
| Image | 2048 | ResNet50 embeddings |
| **Итого** | **~2414** | |

### Параметры модели

```python
LightGBM параметры:
- n_estimators: 500
- learning_rate: 0.02
- max_depth: 12
- num_leaves: 256
- subsample: 0.8
- colsample_bytree: 0.8

```

## 🔍 Важность признаков

### По типам (усредненно)

1. **Табличные признаки:** 85-92% важности
   - Категории товаров
   - Цена
   - Временные признаки

2. **Image features:** 3-9% важности
   - Особенно важны для `real_height` (9.2%)

3. **Текстовые признаки:** 2-6% важности
   - Размерные характеристики из текста

4. **TF-IDF:** 1-4% важности
   - Семантическая информация из описаний


## 🛠️ Troubleshooting

### Проблема: Недостаточно памяти

**Решение:**
- Уменьшите `batch_size` в `05_image_features_extractor.py`
- Обрабатывайте данные частями
- Используйте машину с большим объемом RAM

### Проблема: Медленное извлечение image features

**Решение:**
- Используйте GPU (CUDA или MPS)
- Уменьшите размер батча
- Используйте предвычисленные features (если доступны)
